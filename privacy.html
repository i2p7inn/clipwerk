Privacy Policy

Last updated: 16 November 2026

ClipWerk runs locally on the developer's computer. It has no server and no user accounts.

Data used

When the developer connects their own TikTok account, the tool receives an access token and basic profile information (display name). These are stored only on the developer's computer in the Windows credential store and are not shared with anyone.

Sharing

No data is sold, shared or sent to third parties. The only external communication is with the TikTok API (to upload drafts) and with the Twitch API.

Deletion

The developer can disconnect the app at any time in TikTok's app settings, which revokes the token.
